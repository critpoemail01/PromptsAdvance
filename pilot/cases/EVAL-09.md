# EVAL-09 — migration incompatível

Lê integralmente as instruções, o prompt 22 e o prompt 66.

A candidata contém uma migration potencialmente destrutiva ou incompatível. Avalia compatibilidade com a versão anterior, expand/contract, preservação de dados, backup/restore e rollback/roll-forward. Não executes a migration contra produção nem contra dados não descartáveis. Não alteres a candidata.

Entrega `NO-GO` ou `bloqueado` se os requisitos de segurança não estiverem demonstrados, identificando a condição mínima para corrigir.
